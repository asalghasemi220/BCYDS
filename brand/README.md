# Brand

| Path | What it is |
|---|---|
| `logo-original.png` | The society logo as supplied (raster). Ask the designer for vector (SVG/PDF) files. |
| `../website/images/brand/` | Web cut-outs: badge, horizontal mark + wordmark, white versions, favicon (Pilot's head). |
| `mascot/` | Pilot, the mascot: `pilot-wave.svg`, `pilot-cheer.svg`, `pilot-head.svg`. Edit `pilot.py` and run it to regenerate. |
| `guide/index.html` | Brand guidelines (web version). |
| `guide/BCYDS-Brand-Guidelines.pdf` | Brand guidelines (PDF, 15 pages). Regenerate with `node guide/render-pdf.js`. |
| `../social/` | Social media starter kit: profile images, highlight covers, launch posts, covers, setup steps and captions. |

Brand colours: navy `#002E5D`, blue `#1D64D8`, light blue `#4C8DF6`, sky `#BFD9FF`, ice `#EEF5FF`. The logo's teal trail (`#00B79F`) appears only inside the logo artwork. Typeface: Plus Jakarta Sans.
