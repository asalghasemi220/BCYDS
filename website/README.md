# BCYDS website (test version)

A single static page: `index.html` plus `images/`. No build step. Open `index.html` in a browser, or upload the folder to any static host. Hosting and domain come later.

## Design system
- **Logo:** six petals around a centre, one petal per activity area. The petal colours are the site palette:
  robotics `#2f5bea`, science `#12a19b`, arts `#e04e65`, outdoor learning `#3c8a4c`, life skills `#f0a13a`, hands-on projects `#7b5bd1`, on a deep evergreen `#10231e`.
- **Type:** Bricolage Grotesque (headings), Figtree (text), JetBrains Mono (small labels), all from Google Fonts.
- **Motion:** headline word rotation, hero collage entrance and pointer parallax, slow photo zoom, scrolling verb band, scroll-driven activity tour, reveal-on-scroll, a live "sensor" readout. All motion switches off for visitors who set "reduce motion".
