# BCYDS website (test version)

A single static page: `index.html` plus `images/`. No build step. Open `index.html` in a browser, or upload the folder to any static host. Hosting and domain come later.

## Brand system (taken from the society logo)
- **Logo:** `../brand/logo-original.png` (as supplied). Web cut-outs with transparent backgrounds are in `images/brand/`: the plane-and-trail mark, the wordmark, the full badge, the plane alone, white versions for navy backgrounds, and a favicon.
- **Core colours (sampled from the logo):** navy `#002E5D`, teal `#00B79F`, on white. Teal text on white uses the darker `#00806F` for legibility.
- **Activity colours** (supporting accents only, never larger than the brand colours): robotics `#2D6BE4`, science `#00B79F`, arts `#E85D75`, outdoor learning `#3F9A5A`, life skills `#F2A93B`, hands-on projects `#7A63D8`.
- **Type:** Plus Jakarta Sans (headings), Figtree (text), Caveat (short handwritten notes). Small labels use wide letter-spacing to echo "S O C I E T Y" in the logo.
- **Motifs:** the paper plane and its looping teal trail; the logo's rounded-square frame around key photos.
- **Motion:** the plane flies in and draws its trail, headline word rotation, collage entrance and pointer parallax, slow photo zoom, verb band, scroll-driven activity tour, reveal-on-scroll, handwritten underline, a live "sensor" readout. All motion switches off for visitors who set "reduce motion".
